8. 演练日志

演练规则

  • 公网端口按“公网 IP + 公网端口 + 上游端点”复用：同一出口上不同上游端点可以占用同一个公网端口。
  • 同一出口、同一上游端点的连接即使并发建立，也一定分到不同的公网端口。
  • 连接关闭后，“公网 IP + 公网端口 + 原上游端点”冷却 {{ cooldown_seconds }} 秒，期间不得再分配给该上游；其他上游、其他出口可立即使用该端口。
  • 换址后旧出口退场：已建连接保留原公网 IP 继续收包，关闭后仍在旧出口冷却；新连接只从当前出口分配。
  • 退场出口的连接全关、冷却全到期后自动移除；退场期间可以切回原 IP，原有映射和冷却照常生效。
  • 有出口在退场时，切换到第三个公网 IP 会被拒绝，保持现状；等待退场结束后再切。
  • 上游回包必须命中“公网 IP + 端口 + 上游端点”的映射；冷却中的迟包一律丢弃。
  • 耗尽时按当前出口列出在用与冷却的端口数量，并给出可推进的时间。
